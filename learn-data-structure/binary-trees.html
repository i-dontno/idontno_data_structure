Binary trees: count the nodes, find the height

Data Structures with Python · Build trees, let the page classify them, then use the calculator to see why each formula works.

1. What is a binary tree?

A hierarchical, non-linear structure where every node has at most two children: a left child and a right child. It may also be empty.

  • A node may have 0, 1 or 2 children. A node with no children is a leaf. The topmost node is the root.
  • A tree with n nodes (n ≥ 1) has exactly n − 1 edges.
  • Conventions used here: root is at level 0. Height h = edges on the longest root-to-leaf path, so a lone root has h = 0 and a tree has h + 1 levels. Some books count levels instead; use the toggle in the Formula lab to switch.
  • N = total number of nodes. Level i can hold at most 2i nodes, because the maximum doubles at each level.
FullEvery node has 0 or 2 children. Never exactly one.
CompleteEvery level is full except possibly the last, which is filled left to right.
PerfectEvery internal node has 2 children and all leaves are on one level.
Perfect ⇒ full and complete.
Full and complete together do not always give perfect. Try it in the lab.

  • Trick: a tree is complete exactly when its filled positions are 1, 2, 3 ... N with no gaps. That is why complete trees fit neatly into arrays (heaps).

  • Max nodes for height h: 1 + 2 + 4 + … + 2h = 2h+1 − 1 (geometric series).
  • Min nodes: general h + 1 (a chain) · full 2h + 1 (a spine with one leaf hanging off each internal node) · complete 2h (levels 0 to h−1 full, plus one node at level h) · perfect 2h+1 − 1.

Python: test the three types 
def count(n):  return 0 if n is None else 1 + count(n.left) + count(n.right)
def height(n): return -1 if n is None else 1 + max(height(n.left), height(n.right))

def is_full(n):
    if n is None: return True
    if (n.left is None) != (n.right is None): return False
    return is_full(n.left) and is_full(n.right)

def is_complete(n, i, total):          # call: is_complete(root, 0, count(root))
    if n is None: return True
    if i >= total: return False
    return is_complete(n.left, 2*i+1, total) and is_complete(n.right, 2*i+2, total)

def is_perfect(n): return count(n) == 2**(height(n) + 1) - 1
