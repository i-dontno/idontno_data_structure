Introduction to Arrays

Definition

An array is a linear data structure that stores a finite, ordered collection of elements of the same data type in contiguous (adjacent) memory locations. Each element is identified by its position, called an index (or subscript).

Let's unpack the definition, because every word in it matters in an exam answer:

  • Linear: elements are arranged one after another in a sequence; every element (except the first and last) has exactly one predecessor and one successor.
  • Finite: the array holds a fixed, countable number of elements.
  • Same data type (homogeneous): all elements are integers, or all are floats, and so on. This is what lets the computer calculate where any element lives.
  • Contiguous memory: the elements sit in one unbroken block of memory, side by side.

Why do we need arrays?

Suppose you need to store the marks of 60 students. Without an array you would need 60 separate variables: m1, m2, … m60. You couldn't loop over them, sort them, or find the average without writing 60 lines. An array gives all 60 values one name (marks) and lets you reach any of them by number: marks[0], marks[1], … marks[59]. A single loop can now process all of them.

Why are arrays important?

  • Instant access: any element can be read in constant time, O(1), using its index. This is called random access (or direct access).
  • Building block: stacks, queues, heaps, hash tables, matrices, and graphs (adjacency matrix) are usually built on top of arrays.
  • Hardware-friendly: because elements are adjacent, the CPU cache loads neighbouring elements together, so traversal is very fast in practice. This property is called locality of reference.

Fundamental properties

  1. Homogeneous: all elements have the same type and therefore the same size w.
  2. Contiguous allocation: elements are stored in consecutive memory addresses.
  3. Fixed size (for static arrays): capacity is decided when the array is created.
  4. Random access: address of any element is computed by a formula in O(1) time, without visiting other elements.
  5. Ordered: elements keep the order in which they are placed.

Types of arrays

By number of dimensions

One-dimensional (1D): a single row of elements, accessed with one index A[i].
Two-dimensional (2D): a table/matrix of rows and columns, accessed with A[i][j].
Multi-dimensional: three or more indices, e.g. A[i][j][k] for a 3D grid.

By memory allocation

Static array: size fixed at creation (compile time in C: int a[10];). Cannot grow.
Dynamic array: grows automatically. When full, it allocates a bigger block and copies elements over. A Python list is a dynamic array.

Arrays in Python: list vs array module

Python has no built-in "C-style" array keyword. Instead, we use:

Teacher's note

A Python list can hold [1, "two", 3.0]. This does not break the "homogeneous" rule: internally the list's contiguous block holds references, and every reference has the same size. That's why indexing a list is still O(1).

Memory representation of a 1D array

Because all elements are the same size and stored back to back, the address of element A[i] is:

LOC(A[i]) = B + w × (i − LB)

where B = base address, w = size of one element in bytes, LB = lower bound. When LB = 0 (as in Python and C), this simplifies to LOC(A[i]) = B + w × i.

Worked Example 1 (non-zero lower bound)

An array A[5 … 20] of 2-byte integers has base address 2000. Find (a) the number of elements and (b) the address of A[12].

  • (a) n = UB − LB + 1 = 20 − 5 + 1 = 16 elements
  • (b) LOC(A[12]) = 2000 + 2 × (12 − 5) = 2000 + 14 = 2014

Memory representation of a 2D array

Memory is a single line of addresses, so a table of rows and columns must be "flattened". There are two standard ways:

Row-major order

Store row 0 completely, then row 1, then row 2 … Used by C, C++, Python (NumPy default).

Column-major order

Store column 0 completely, then column 1 … Used by Fortran, MATLAB, R.

For an array A[LR … UR][LC … UC] with M = UR − LR + 1 rows and N = UC − LC + 1 columns:

Row-major:    LOC(A[i][j]) = B + w × [ (i − LR) × N + (j − LC) ]
Column-major: LOC(A[i][j]) = B + w × [ (j − LC) × M + (i − LR) ]
How to remember

In row-major, to reach row i you must skip (i − LR) full rows, and each full row has N elements. In column-major you skip (j − LC) full columns, each with M elements.

Worked Example 2

An array A[1 … 4][1 … 5] stores 4-byte integers with base address 500. Find the address of A[3][4] in row-major and column-major order.

  • M = 4 − 1 + 1 = 4 rows, N = 5 − 1 + 1 = 5 columns
  • Row-major: 500 + 4 × [(3 − 1) × 5 + (4 − 1)] = 500 + 4 × 13 = 552
  • Column-major: 500 + 4 × [(4 − 1) × 4 + (3 − 1)] = 500 + 4 × 14 = 556

Operations: Creation, Traversal, Insertion, Deletion

The four basic operations on an array are explained below. All algorithms use 0-based indexing (as in Python), with n = number of elements currently stored and CAP = capacity of the array.

3.1 Creation

Creation means reserving a contiguous block of memory for the array and (optionally) giving its elements initial values. In a static array you must state the capacity up front.

ALGORITHM CREATE(CAP)
1. Allocate a contiguous block of CAP × w bytes
2. Set base address B ← address of the first byte
3. Set n ← 0                       // no elements stored yet
4. (Optional) for i ← 0 to CAP − 1: A[i] ← initial value
5. Return A

3.2 Traversal

Traversal means visiting (processing) every element exactly once, usually from the first index to the last. "Processing" could be printing, summing, counting, or searching.

ALGORITHM TRAVERSE(A, n)
1. Set i ← 0
2. Repeat while i < n:
3.     PROCESS(A[i])              // e.g. print or add to sum
4.     i ← i + 1
5. Exit

The loop body runs exactly n times, so traversal takes Θ(n) time (always linear: best, average and worst cases are the same).

3.3 Insertion

Insertion adds a new element at a given position pos. Since array elements must stay contiguous, every element from pos to the end has to move one place to the right to open a gap.

  • Insert at end (pos = n): no shifting. O(1).
  • Insert at beginning (pos = 0): all n elements shift. O(n).
  • Insert at position pos: (n − pos) elements shift. O(n) in the worst case.
ALGORITHM INSERT(A, n, CAP, pos, item)
1. If n = CAP then print "OVERFLOW" and exit
2. If pos < 0 or pos > n then print "INVALID POSITION" and exit
3. Set j ← n − 1
4. Repeat while j ≥ pos:              // shift right, starting from the END
5.     A[j + 1] ← A[j]
6.     j ← j − 1
7. A[pos] ← item                      // place the new item in the gap
8. n ← n + 1
9. Exit
Why shift from the end?

If you shift from the left (A[pos+1] ← A[pos] first), you overwrite A[pos+1] before saving it, and the same value is copied all the way down the array. Always move the last element first.

3.4 Deletion

Deletion removes the element at position pos. To fill the hole and keep the array contiguous, every element after pos moves one place to the left.

  • Delete from end (pos = n − 1): no shifting. O(1).
  • Delete from beginning (pos = 0): n − 1 elements shift. O(n).
  • Delete at position pos: (n − pos − 1) elements shift.
  • Delete by value: first search for the value (O(n)), then delete at its index.
ALGORITHM DELETE(A, n, pos)
1. If n = 0 then print "UNDERFLOW" and exit
2. If pos < 0 or pos ≥ n then print "INVALID POSITION" and exit
3. item ← A[pos]                      // save the element being removed
4. Repeat for j ← pos to n − 2:       // shift left, starting just after pos
5.     A[j] ← A[j + 1]
6. n ← n − 1
7. Return item

Overflow & Underflow

Overflow: trying to insert into a full array (n = CAP). Underflow: trying to delete from an empty array (n = 0). Always check these conditions first in your algorithm; examiners look for them.

* For a static array with free space. For a Python list, append is amortised O(1): occasionally the list is full, so Python allocates a larger block and copies all elements (O(n)), but this is rare enough that the average cost per append stays constant.

Why is average insertion O(n)?

If every position 0 … n is equally likely, the number of shifts is n, n−1, …, 1, 0. The average is (n + (n−1) + … + 0) / (n + 1) = n / 2. Dropping the constant ½ gives O(n). The same reasoning gives (n − 1)/2 shifts on average for deletion.

Space complexity

  • Storing n elements needs O(n) space (exactly CAP × w bytes for a static array).
  • Traversal, insertion and deletion need only a few extra variables (i, j, item): O(1) auxiliary space. They work in place.

Applications, Advantages & Disadvantages

Applications of arrays

1. Storing lists of data

Marks, salaries, product prices, sensor readings: any collection of same-type values processed together.

2. Implementing other data structures

Stacks, queues (including circular queues), heaps/priority queues and hash tables are commonly built on arrays.

3. Matrices & scientific computing

2D arrays represent matrices for addition, multiplication, solving equations, and transformations in graphics.

4. Images & multimedia

An image is a 2D array of pixels; audio is a 1D array of samples; video is a sequence of 2D frames.

5. Sorting & searching

Algorithms such as binary search, quick sort and merge sort depend on O(1) index access.

6. Lookup tables & counting

Frequency counts (count[x] += 1), precomputed tables, and mapping small integers to values.

7. Polynomial representation

3x² + 2x + 5 is stored as [5, 2, 3], where index = power of x.

8. Graphs

An adjacency matrix is a 2D array where adj[u][v] = 1 if there is an edge from u to v.

9. Buffers & scheduling

Keyboard buffers, network packet buffers and CPU scheduling tables use fixed-size arrays.

10. Databases & spreadsheets

Table records and spreadsheet cells are stored and processed as arrays of rows and columns.

Advantages of arrays

✔ Random access in O(1)

Any element is reached directly using its index via the address formula.

✔ Simple to use

Easy to declare, understand and loop over. Supported by every language.

✔ No extra memory per element

Unlike linked lists, there are no pointers stored with each element.

✔ Cache-friendly

Contiguous storage gives locality of reference, making traversal very fast in practice.

✔ Foundation for other structures

Stacks, queues, heaps, hash tables and matrices can all be implemented using arrays.

✔ Efficient sorting & binary search

Index access makes algorithms like binary search (O(log n)) possible.

Disadvantages of arrays

✘ Fixed size (static arrays)

Capacity must be known in advance. Too small causes overflow; too large wastes memory.

✘ Costly insertion & deletion

Elements must be shifted, which takes O(n) time in the worst case.

✘ Needs contiguous memory

A large array needs one unbroken free block; allocation may fail even when enough total memory exists in pieces.

✘ Homogeneous elements

Classic arrays store only one data type (Python lists work around this using references).

✘ Resizing is expensive

Growing a dynamic array means allocating a new block and copying all elements: O(n) for that step.

✘ No bounds checking in some languages

In C, accessing a[10] on a 10-element array silently reads invalid memory.

Special cases & edge cases

SituationCorrect behaviour
Traversing an empty array (n = 0)Loop runs zero times; handle "array is empty" message if needed.

Common mistakes

Watch out
  • Shifting in the wrong direction: insertion must shift from the right end toward pos; deletion from pos toward the right end.
  • Off-by-one errors: valid indices are 0 … n − 1, not 1 … n. Insertion allows pos = n, deletion doesn't.
  • Forgetting to update n after insertion or deletion.
  • Python insert() never raises an error for a large position: a.insert(100, x) on a 4-element list simply appends. Negative positions count from the end. Write your own bounds checks when the exam asks you to.
  • Removing items while looping over the same list: elements get skipped because indices shift under the loop. Loop over a copy (for x in a[:]) or build a new list.
  • Creating 2D lists with [[0]*n]*m: all m rows are the same object, so changing one row changes all. Use [[0]*n for _ in range(m)].
  • Assuming b = a copies the array: it creates a second name for the same list. Use a.copy() or a[:].

Important examination points

Remember for exams
  • Number of elements in A[LB … UB] = UB − LB + 1.
  • 1D address: LOC(A[i]) = B + w(i − LB).
  • Row-major: B + w[(i − LR)N + (j − LC)]; Column-major: B + w[(j − LC)M + (i − LR)].
  • Shifts for insertion at pos = n − pos; for deletion at pos = n − pos − 1 (0-based).
  • Many textbooks write algorithms with 1-based indices (LA[1 … N], insert at K: shift while J ≥ K). The logic is identical; just be consistent within one answer.
  • Array = random access; linked list = sequential access.
  • Always mention overflow/underflow checks in insertion/deletion algorithms.

This is the program to understand for exams. It builds a fixed-capacity array and performs shifting by hand, exactly like the INSERT and DELETE algorithms in Section 3, including overflow and underflow checks.

# Program 2: A fixed-capacity (static) array built from scratch.
# Shows exactly how insertion and deletion SHIFT elements,
# and how OVERFLOW and UNDERFLOW are detected.

class StaticArray:
    def __init__(self, capacity):
        self.capacity = capacity          # maximum number of elements
        self.data = [None] * capacity     # contiguous block of 'capacity' cells
        self.n = 0                        # current number of elements

    def traverse(self):
        """Visit elements a[0] .. a[n-1]."""
        if self.n == 0:
            print("  Array is empty")
            return
        print("  ", end="")
        for i in range(self.n):
            print(self.data[i], end=" ")
        print(f"  (n={self.n}, capacity={self.capacity})")

    def insert(self, pos, item):
        """Insert item at index pos (0 <= pos <= n)."""
        if self.n == self.capacity:
            raise OverflowError("Overflow: array is full")
        if pos < 0 or pos > self.n:
            raise IndexError(f"Invalid position {pos}")
        # Shift a[n-1] .. a[pos] one place RIGHT, starting from the END
        j = self.n - 1
        while j >= pos:
            self.data[j + 1] = self.data[j]
            j -= 1
        self.data[pos] = item
        self.n += 1
        return self.n - 1 - pos           # number of shifts performed

    def delete(self, pos):
        """Delete and return the element at index pos (0 <= pos < n)."""
        if self.n == 0:
            raise IndexError("Underflow: array is empty")
        if pos < 0 or pos >= self.n:
            raise IndexError(f"Invalid position {pos}")
        item = self.data[pos]
        # Shift a[pos+1] .. a[n-1] one place LEFT, starting from pos+1
        for j in range(pos, self.n - 1):
            self.data[j] = self.data[j + 1]
        self.data[self.n - 1] = None      # clear the old last cell
        self.n -= 1
        return item


arr = StaticArray(6)
for value in [10, 20, 30, 40]:
    arr.insert(arr.n, value)              # insert at end
print("Initial array:")
arr.traverse()

shifts = arr.insert(1, 15)
print(f"\nInsert 15 at index 1 ({shifts} shifts):")

Delete index 10 -> Invalid position 10
Delete from empty array -> Underflow: array is empty
Code walkthrough
  • self.data = [None] * capacity reserves all cells up front, imitating a static block of memory.
  • In insert, the while j >= pos loop starts at n − 1 and moves left, so no value is overwritten before it is copied.
  • In delete, the for loop starts at pos and moves right, pulling each later element one step left.
  • Inserting 15 at index 1 into 4 elements needed 4 − 1 = 3 shifts, matching the formula n − pos.

# Column-major traversal: finish a whole column, then move to the next column

# ---------- Address calculation ----------
def address_1d(base, w, i, lb=0):
    """LOC(A[i]) = B + w * (i - LB)"""
    return base + w * (i - lb)

def address_row_major(base, w, i, j, lr, lc, ncols):
    """LOC(A[i][j]) = B + w * [ (i - LR) * N + (j - LC) ]"""
    return base + w * ((i - lr) * ncols + (j - lc))

def address_col_major(base, w, i, j, lr, lc, nrows):
    """LOC(A[i][j]) = B + w * [ (j - LC) * M + (i - LR) ]"""
    return base + w * ((j - lc) * nrows + (i - lr))

print("\nA[5..20], B=2000, w=2 -> LOC(A[12]) =", address_1d(2000, 2, 12, lb=5))
# A[1..4][1..5]: M = 4 rows, N = 5 columns, B = 500, w = 4
print("A[1..4][1..5], B=500, w=4:")
print("  Row-major    LOC(A[3][4]) =", address_row_major(500, 4, 3, 4, 1, 1, 5))
print("  Column-major LOC(A[3][4]) =", address_col_major(500, 4, 3, 4, 1, 1, 4))

Short programs that show arrays in action: max/min, linear search, in-place reversal, frequency counting (lookup table) and polynomial evaluation.

# Program 5: Small applications of arrays

def find_max_min(a):
    """Single traversal to find the largest and smallest element."""
    largest = smallest = a[0]
    for x in a[1:]:
        if x > largest:
            largest = x
        if x < smallest:
            smallest = x
    return largest, smallest

def reverse_in_place(a):
    """Two-pointer swap: O(n) time, O(1) extra space."""
    left, right = 0, len(a) - 1
    while left < right:
        a[left], a[right] = a[right], a[left]
        left += 1
        right -= 1

def linear_search(a, key):
    """Return index of key, or -1 if not found."""
    for i in range(len(a)):
        if a[i] == key:
            return i
    return -1

def frequency(a, max_value):
    """Count occurrences using an array as a lookup table."""
    count = [0] * (max_value + 1)
    for x in a:
        count[x] += 1
    return count

def evaluate_polynomial(coeff, x):
    """coeff[i] is the coefficient of x^i  (array representation of a polynomial)."""
    result = 0
    for power in range(len(coeff) - 1, -1, -1):   # Horner's rule
        result = result * x + coeff[power]
    return result


data = [34, 7, 23, 32, 5, 62, 7]
print("Data          :", data)
print("Max, Min      :", find_max_min(data))
print("Search 32     : index", linear_search(data, 32))
print("Search 100    : index", linear_search(data, 100))

reverse_in_place(data)
print("Reversed      :", data)

dice = [1, 3, 3, 6, 2, 3, 6, 1]
print("Dice counts   :", frequency(dice, 6)[1:], "(faces 1..6)")

# 3x^2 + 2x + 5 stored as [5, 2, 3]
print("3x^2+2x+5 at x=4 :", evaluate_polynomial([5, 2, 3], 4))

Practice & Assessment

A. Conceptual questions

1. Define an array. Why must its elements be of the same type?

An array is a linear data structure storing a finite collection of same-type elements in contiguous memory, accessed by index. Same type means every element has the same size w, which is what allows the address formula B + w(i − LB) to locate any element in O(1).

2. Why is insertion at the beginning of an array O(n) but O(1) in a linked list?

In an array, all n elements must shift right by one to free index 0. In a linked list, the new node just points to the old head, and the head pointer is updated: a constant number of steps.

3. Differentiate row-major and column-major order with an example.

For a 2 × 3 matrix [[a, b, c], [d, e, f]], row-major stores a b c d e f (row by row) while column-major stores a d b e c f (column by column).

4. What are overflow and underflow in arrays?

Overflow: inserting into a full array (n = CAP). Underflow: deleting from an empty array (n = 0).

5. List four applications and three disadvantages of arrays.

Applications: storing records/marks, implementing stacks and queues, matrices/images, lookup tables, polynomial representation, adjacency matrices. Disadvantages: fixed size, O(n) insertion/deletion due to shifting, need for contiguous memory.
