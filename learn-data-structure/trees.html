1. Meet the Tree Data Structure

A tree is a non-linear structure of nodes joined by edges, with exactly one path between any two nodes. Click any node to inspect it.

Yellow = selected · green = ancestors · blue = descendants · red dashed = siblings
  • Edges: a tree with N nodes always has N − 1 edges.
  • Level / depth of a node = number of edges from the root (root is level 0). Height of the tree = depth of its deepest node.
  • Degree of a node = number of children. Degree of the tree = largest node degree. Leaf degree = 0.
  • Ancestors of a node are every node on the path up to the root (its parent, grandparent, ...). Subtree = a node plus all its descendants.
  • Where trees appear: file systems, the HTML DOM, organisation charts, database indexes.

BST rule: for every node, all keys in its left subtree are smaller and all keys in its right subtree are larger (not just its direct children).

Python: BST insert and search

class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

def insert(root, key):
    if root is None:
        return Node(key)
    if key < root.data:
        root.left = insert(root.left, key)
    elif key > root.data:
        root.right = insert(root.right, key)
    return root

def search(root, key):
    if root is None or root.data == key:
        return root
    if key < root.data:
        return search(root.left, key)
    return search(root.right, key)
