Learn Data Structures with idontno: static course website
=========================================================

What's inside
  index.html           Course home (modules, lessons, progress, Continue button)
  <lesson>.html        One page per lesson (18), each wrapping the original post
  assets/              site.css, site.js, data.js (course outline + search index), favicon.svg

How to open it
  Double-click index.html. It works straight from the folder with no server needed.

How to put it online (any static host)
  Netlify:       app.netlify.com/drop, then drag this whole folder onto the page.
  GitHub Pages:  push the folder's contents to a repository, then Settings > Pages > Deploy from branch.
  Your own host: upload every file and keep the folder structure the same.

How to add or update a lesson later
  The pages are generated, so the sidebar, home cards and Previous/Next
  links are written into every page. To add a new lesson (for example a
  "Coming soon" topic) or change an existing post, send me the post HTML
  and I'll rebuild the whole folder. Then re-upload it.

Notes
  - Progress ("Mark as complete") is saved in each visitor's browser only.
    There are no accounts and no data is collected.
  - Press "/" on any page to jump to search.
  - Coming soon (not yet written): Python built-in data types, Recursion,
    Expression trees & Huffman coding, Hashing.
