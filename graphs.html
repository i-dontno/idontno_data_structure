Graphs: the map of connections

Cities and roads, friends and followers, web pages and links. Learn what a graph is, build your own, and practise writing its adjacency matrix and list.

1. What is a graph?

A graph is a way to show things and the connections between them.

A graph is a non-linear data structure made of vertices (also called nodes) and edges (the connections). Arrays and linked lists keep data in a line. A graph does not follow any order, so it can show relationships of any shape.

Example: On a map, each city is a vertex and each road joining two cities is an edge. Together they show how the cities are linked.

Words you must know

Vertex (node)A point of the graph, such as a city or a person. It can have a label.
Edge (arc)A line that joins two vertices. It can have a label too.
Adjacent / neighbourTwo vertices joined by an edge are adjacent. They are neighbours.
DegreeThe number of edges at a vertex. In a directed graph we count in-degree (arrows coming in) and out-degree (arrows going out).
PathA route from one vertex to another along edges.
CycleA path that starts and ends at the same vertex.

Graphs in real life

  • In this post we use simple graphs: no edge joins a vertex to itself, and no two vertices have more than one edge between them.
  • With V vertices, an undirected simple graph can have at most V(V − 1)/2 edges.

4. Adjacency matrix

An adjacency matrix stores a graph as a table of 0s and 1s.

  • If the graph has n vertices, make an n × n table, mat[n][n], filled with 0.
  • If there is an edge from vertex i to vertex j, set mat[i][j] = 1. If there is no edge, it stays 0.
  • Undirected graph: an edge joins both ways, so set mat[i][j] and mat[j][i]. The matrix is symmetric.
  • Directed graph: set only mat[from][to]. Row = where the edge starts, column = where it ends.
  • Weighted graph: store the weight instead of 1. A 0 still means "no edge".

Build it step by step

  • The diagonal (mat[i][i]) is 0, because no vertex is joined to itself.
  • In an undirected matrix, the sum of a row is the degree of that vertex. In a directed matrix, a row sum is the out-degree and a column sum is the in-degree.

5. Adjacency list

An adjacency list gives every vertex its own list of neighbours.

  • Make an array of n lists, adjList[n]. The size equals the number of vertices.
  • adjList[i] holds all vertices that are connected to vertex i.
  • Undirected graph: for edge a – b, put b in the list of a and a in the list of b.
  • Directed graph: for edge a → b, put b only in the list of a. A vertex with no outgoing edge has an empty list.
  • Weighted graph: store pairs (neighbour, weight).

7. Python code

n = 3
edges = [(0, 1), (0, 2), (1, 2)]          # undirected graph

mat = [[0] * n for _ in range(n)]         # n x n table of zeros
for u, v in edges:
    mat[u][v] = 1
    mat[v][u] = 1                         # delete this line for a directed graph

for row in mat:
    print(row)
# [0, 1, 1]
# [1, 0, 1]
# [1, 1, 0]
n = 3
edges = [(1, 0), (2, 0), (1, 2)]          # directed: (from, to)

adj = [[] for _ in range(n)]              # one empty list per vertex
for u, v in edges:
    adj[u].append(v)                      # add adj[v].append(u) for an undirected graph

for i in range(n):
    print(i, "->", adj[i])
# 0 -> []
# 1 -> [0, 2]
# 2 -> [0]
n = 4
edges = [(0, 1, 4), (0, 2, 2), (1, 2, 5), (2, 3, 8)]   # (u, v, weight), undirected

mat = [[0] * n for _ in range(n)]         # 0 means "no edge", so weights must not be 0
adj = [[] for _ in range(n)]
for u, v, w in edges:
    mat[u][v] = mat[v][u] = w
    adj[u].append((v, w))
    adj[v].append((u, w))

print(mat[0])    # [0, 4, 2, 0]
print(adj[2])    # [(0, 2), (1, 5), (3, 8)]
